# Build and dependency inventory

The v1.0.1 frontend uses native custom elements, DOM, CSS and Home Assistant's supplied `hass` API. The JavaScript bundle has **no third-party runtime modules, remote fonts, runtime downloads or generated brand assets**. The renderer preserves the existing TI design and uses Home Assistant's `ha-icon` for named icons. The build rejects non-`src/` inputs and external module imports.

| Development dependency | Pinned version | Package licence | Role |
| --- | --- | --- | --- |
| esbuild and its platform binary | 0.28.2 | MIT | Bundle/minify source |
| @playwright/test | 1.65.1 | Apache-2.0 | Browser regression runner |
| playwright / playwright-core | 1.65.1 | Apache-2.0 | Test browser control |
| @mdi/js | 7.4.47 | Icons Apache-2.0; package code MIT per bundled notice | Actual icons in synthetic browser fixtures only |

Versions and integrity hashes are in [package-lock.json](https://github.com/senyo888/thermal-intelligence/blob/v1.0.1/package-lock.json). Licence fields and installed package notices were inspected for these exact versions. Optional `fsevents` is MIT. Browser binaries and their notices remain in Playwright's development cache; neither they nor `node_modules` enter the bundle. This inventory describes actual inclusion, not a blanket legal determination about unrelated future dependencies.

[Fixture icons](https://github.com/senyo888/thermal-intelligence/blob/v1.0.1/tests/fixtures/icons.js) contain selected MDI SVG paths generated by [the fixture build script](https://github.com/senyo888/thermal-intelligence/blob/v1.0.1/scripts/build-fixture-icons.mjs). Keep the [Pictogrammers package notice](https://github.com/senyo888/thermal-intelligence/blob/v1.0.1/tests/fixtures/ICONS-LICENSE.txt) and [Apache 2.0 licence](https://github.com/senyo888/thermal-intelligence/blob/v1.0.1/tests/fixtures/APACHE-2.0.txt) with them. Regenerate with `node scripts/build-fixture-icons.mjs`; these assets are absent from the runtime bundle.

To reproduce the published v1.0.1 package, check out `b9150b79bbc378af5542e39b6ee42de730d6dcfd`, the source recorded in its [release manifest](https://github.com/senyo888/thermal-intelligence/releases/download/v1.0.1/manifest.json). Earlier package identities are recorded with [v1.0.0](v1.0.0-package.md) and [RC.3](rc-3.md). From the matching checkout, build with Node 22 or newer and `npm ci`, then `npm run build`. Source, lockfile, build scripts and the GPL-3.0-only licence must accompany a distributed version. Source maps are disabled. CI rebuilds and compares the checked-in bundle, runs model/editor/command tests, and runs the synthetic Chromium suite. GitHub Project checks run the same build and test checks for candidate and beta source.

See [source provenance](source-provenance.md), [licence scope](licensing-options.md) and [distribution](distribution.md). Artwork and documentation have separate reuse terms.

The development-only [secret-scan helper](../scripts/security/scan_secrets.sh) follows HI's tracked-file/full-history workflow and retains its [MIT notice](../scripts/security/HI-LICENSE.txt). It is not bundled into the card.
