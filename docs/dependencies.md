# Build and dependency inventory

Candidate `0.1.0-beta.1` uses native custom elements, DOM, CSS and Home Assistant's supplied `hass` API. The JavaScript bundle has **no third-party runtime modules, remote fonts, runtime downloads or generated brand assets**. The renderer preserves the existing TI design and uses Home Assistant's `ha-icon` for named icons. The build rejects non-`src/` inputs and external module imports.

| Development dependency | Pinned version | Package licence | Role |
| --- | --- | --- | --- |
| esbuild and its platform binary | 0.28.2 | MIT | Bundle/minify source |
| @playwright/test | 1.64.1 | Apache-2.0 | Browser regression runner |
| playwright / playwright-core | 1.64.1 | Apache-2.0 | Test browser control |
| @mdi/js | 7.4.47 | Icons Apache-2.0; package code MIT per bundled notice | Actual icons in synthetic browser fixtures only |

Versions and integrity hashes are in [package-lock.json](https://github.com/senyo888/thermal-intelligence/blob/senyo888-patch-1/package-lock.json). Licence fields and installed package notices were inspected for these exact versions. Optional `fsevents` is MIT. Browser binaries and their notices remain in Playwright's development cache; neither they nor `node_modules` enter the bundle. This inventory describes actual inclusion, not a blanket legal determination about unrelated future dependencies.

[Fixture icons](https://github.com/senyo888/thermal-intelligence/blob/senyo888-patch-1/tests/fixtures/icons.js) contain 30 selected MDI SVG paths generated by [the fixture build script](https://github.com/senyo888/thermal-intelligence/blob/senyo888-patch-1/scripts/build-fixture-icons.mjs). They replace the original circle placeholders for meaningful visual comparison. Keep the [Pictogrammers package notice](https://github.com/senyo888/thermal-intelligence/blob/senyo888-patch-1/tests/fixtures/ICONS-LICENSE.txt) and [Apache 2.0 licence](https://github.com/senyo888/thermal-intelligence/blob/senyo888-patch-1/tests/fixtures/APACHE-2.0.txt) with them. Regenerate with `node scripts/build-fixture-icons.mjs`; these assets are absent from the runtime bundle.

Build with Node 22 or newer and `npm ci`, then `npm run build`. Source, lockfile, build scripts and the GPL-3.0-only licence must accompany a distributed version. Source maps are disabled. CI rebuilds and compares the checked-in bundle, runs model/editor/command tests, and runs the synthetic Chromium suite. CI is configured locally; a successful local run does not establish a successful GitHub run for an unpublished branch.

See [source provenance](source-provenance.md), [licence scope](licensing-options.md) and [distribution](distribution.md). Marketing concepts and documentation remain subject to their separate, unselected reuse terms.

The development-only [secret-scan helper](../scripts/security/scan_secrets.sh) follows HI's tracked-file/full-history workflow and retains its [MIT notice](../scripts/security/HI-LICENSE.txt). It is not bundled into the card.
