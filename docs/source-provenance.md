# Source attribution

Thermal Intelligence is created and maintained by **[Senyo (senyo888)](https://github.com/senyo888)**. The standalone thermostat adapts the existing TI renderer, dial, styling and detail panels, with portable provider, configuration and command layers.

Original TI software and build scripts use [GPL-3.0-only](../LICENSE). Required third-party notices are retained with their components; the [dependency inventory](dependencies.md) identifies build tools and test-only icons. Home Assistant supplies the platform UI components, named icons and service APIs used by the card.

The development secret-scan helper adapts Humidity Intelligence's helper and retains its [MIT notice](../scripts/security/HI-LICENSE.txt). It is not included in the thermostat bundle.

Images are presentation assets, not runtime dependencies. See [Image notes](image-notes.md) for their context and [licence scope](licensing-options.md) for reuse boundaries.
