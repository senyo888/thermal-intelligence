# Image notes

The gallery contains two kinds of images:

- **Beta component captures:** `thermostat.png`, `thermostat-expanded.png`, `preset-details.png` and `lock-controls.png` show the actual beta.2 component with synthetic data. The lock example has no configured code. They illustrate controls retained in beta.4; they are not new beta.4 captures.
- **Anonymised installation examples:** the other thermostat, window and dashboard examples preserve the supplied readings and states while replacing identifying labels. Their exact source builds were not recorded. Some schedule, ownership and cutoff indicators belong to the wider TI system and are outside the standalone beta.

Installation images use assisted image editing for anonymisation and were visually compared with the originals. They are illustrative, not pixel-comparison or physical-heating evidence. Original cropping and partially visible rows remain. Personal photo metadata was removed; content credentials are retained where present.

The header is generated presentation artwork, not a screenshot. Image-editing prompts, originals and detailed working records are kept privately. Documentation and artwork are subject to the separate [reuse terms](licensing-options.md).
