# Release candidate RC.2

[RC.2 is published](https://github.com/senyo888/thermal-intelligence/releases/tag/v0.1.0-rc.2). The [release guide](https://github.com/senyo888/thermal-intelligence/blob/bella/ti-rc3-candidate-20261113/docs/rc.md) records its exact source, three asset hashes and rollback requirements. See the [dated validation](https://github.com/senyo888/thermal-intelligence/blob/bella/ti-rc3-candidate-20261113/docs/rc2-validation.md) for scoped installation, control and physical-heating evidence and the recovered controller incident.

On Home Assistant 2026.11 and later, start with [Marketplace installation](https://github.com/senyo888/thermal-intelligence/blob/bella/ti-rc3-candidate-20261113/docs/marketplace.md). On older systems, see [HACS](https://github.com/senyo888/thermal-intelligence/blob/bella/ti-rc3-candidate-20261113/docs/hacs.md). Select `v0.1.0-rc.2` explicitly.

The picker name is **Thermal Intelligence Thermostat · RC**; saved cards retain `custom:thermal-intelligence-beta-card`. Load only one beta/RC trial module, preserve legacy TI, and retain configuration plus module for rollback. Explicit optional-switch enrollment uses schema 2.
