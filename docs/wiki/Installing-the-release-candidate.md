# Release candidate RC.3

[RC.3 is published](https://github.com/senyo888/thermal-intelligence/releases/tag/v0.1.0-rc.3). The [release guide](https://github.com/senyo888/thermal-intelligence/blob/main/docs/rc-3.md) records its exact source, three asset hashes, installation steps and rollback requirements.

On Home Assistant 2026.11 and later, start with [Marketplace installation](https://github.com/senyo888/thermal-intelligence/blob/main/docs/marketplace.md). On older systems, see [HACS](https://github.com/senyo888/thermal-intelligence/blob/main/docs/hacs.md). Select `v0.1.0-rc.3` explicitly, preserve legacy TI and load exactly one trial module.

The released module passed passive manual Lab checks. Named-release Marketplace acceptance, physical-client testing and a formal soak remain incomplete. Earlier RC.2 installation and heating evidence does not establish those results for RC.3. See [validation limits](https://github.com/senyo888/thermal-intelligence/blob/main/docs/rc-3.md#validation-limits).
