# Release candidate RC.2

RC.2 is in preparation and is not published yet. The [candidate guide](https://github.com/senyo888/thermal-intelligence/blob/develop/docs/rc.md) records its behavior, reproducible package and acceptance limits.

On Home Assistant 2026.11 and later, start with [Marketplace installation](Installing-with-Marketplace). On older systems, see [HACS](HACS-custom-repository). Select the exact named release only after publication.

The picker name is **Thermal Intelligence Thermostat · RC**; saved cards retain `custom:thermal-intelligence-beta-card`. Load only one beta/RC trial module, preserve legacy TI, and retain configuration plus module for rollback. Explicit optional-switch enrollment uses schema 2.
