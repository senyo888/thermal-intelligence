# Install with Marketplace

For Home Assistant 2026.11 and later, follow the [Marketplace installation guide](https://github.com/senyo888/thermal-intelligence/blob/develop/docs/marketplace.md). It covers adding the TI repository, prerelease selection, resources, verification and recovery. TI is a Dashboard card; it needs no TI controller or backend integration.

RC.2 is not published yet. RC.1 remains the published prerelease. A source or package check does not establish Marketplace install, update or removal acceptance. Keep existing legacy TI separate and load exactly one trial module.
