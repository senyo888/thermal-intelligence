# Install with Marketplace

The named download in this guide is **RC.3**. The [1.0.0 package](https://github.com/senyo888/thermal-intelligence/blob/c7135e760259ded874d18f23963f4afbdca73238/docs/v1.0.0-package.md) is awaiting release. Its verification notes identify the rebuilt module and the earlier module used for installation checks.

For Home Assistant 2026.11 and later, follow the [Marketplace installation guide](https://github.com/senyo888/thermal-intelligence/blob/main/docs/marketplace.md). It covers adding the TI repository, prerelease selection, resources, verification and recovery. After a fresh install, open a new browser session and check the version the card shows. For a published TI release, Marketplace downloads the card and licence attached to that release. TI is a Dashboard card; it needs no TI controller or backend integration.

RC.3 is published. Its exact module passed passive manual Lab checks; named-release Marketplace acceptance remains incomplete. [Validation and limits](https://github.com/senyo888/thermal-intelligence/blob/main/docs/rc-3.md#validation-limits) keep those checks separate from earlier RC.2 installation evidence. Preserve legacy TI and load exactly one trial module.
