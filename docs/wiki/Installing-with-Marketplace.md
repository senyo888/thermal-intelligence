# Install with Marketplace

For 1.0.0, select **v1.0.0** when the tag is available, then choose **Thermal Intelligence Thermostat** in the dashboard picker. Use the [version-specific Marketplace steps](https://github.com/senyo888/thermal-intelligence/blob/main/docs/marketplace.md) or check the [available releases](https://github.com/senyo888/thermal-intelligence/releases).

Marketplace is available on Home Assistant 2026.11 and later. It installs a dashboard resource. After installation, open a fresh dashboard tab and check the card’s version and selected thermostat.

RC.3 is published. Its exact module passed passive manual Lab checks; named-release Marketplace acceptance remains incomplete. [Validation and limits](https://github.com/senyo888/thermal-intelligence/blob/main/docs/rc-3.md#validation-limits) keep those checks separate from earlier RC.2 installation evidence. Preserve legacy TI and load exactly one trial module.
