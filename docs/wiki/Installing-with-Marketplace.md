# Install with Marketplace

For Home Assistant 2026.11 and later, follow the [Marketplace installation guide](https://github.com/senyo888/thermal-intelligence/blob/main/docs/marketplace.md). It covers adding the TI repository, prerelease selection, resources, verification and recovery. TI is a Dashboard card; it needs no TI controller or backend integration.

RC.3 is published. Its exact module passed passive manual Lab checks; named-release Marketplace acceptance remains incomplete. [Validation and limits](https://github.com/senyo888/thermal-intelligence/blob/main/docs/rc-3.md#validation-limits) keep those checks separate from earlier RC.2 installation evidence. Preserve legacy TI and load exactly one trial module.
