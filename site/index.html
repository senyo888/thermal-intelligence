Understand the response

A clearer picture of your room.

01The arc and the ring
The outer arc follows reported state and temperature response. The fine ring shows measured temperature slope, with readable direction, rate and units.
02A chip with context
Heating, Cooling, Idle, a VT heat request or reported valve opening: the chip follows the observations available. Tap to see the source behind the status.
03A small LED, a fuller picture
Green signals readiness; amber highlights restrictions or incomplete observations; red marks disconnection or an unavailable thermostat. Tap for provider details and request status.
04Detail when you want it
The chevron reveals supported modes, presets and provider features. Top-row readings open focused panels. The everyday face stays simple.

Set up your first room in 1.0.0

In the 1.0.0 module, choose Edit dashboard → Add card → Thermal Intelligence Thermostat. Select the room’s climate entity, leave Provider on Automatic and save. The dial shows that thermostat’s current temperature and target in your Home Assistant unit, °F or °C.

Using Versatile Thermostat?

Edit the card and open Readings and icons. Select Find VT sources, check a suggested reading and choose Use this source. Or open Top row icon settings → VT readings and tick a value VT already reports, such as outside temperature.

Using your own sensors?

Choose your room humidity sensor in percent, a temperature rate in degrees per hour, or a valve opening in percent. The preview shows the source and value before you save. You can mix these readings with VT’s. In Humidity display, drag the four markers along the colour bar or enter exact percentages below it.

Read the Plum card

The room is at 19.1°C with a 10°C target. The thermostat reports Idle, and the trend shows the room is still warming at 0.06°C per hour.

Arrange the top row and save it

In the dashboard editor, open Readings and icons → Top row icon settings. Tick a reading and drag its handle or use the arrows within its group. Version 1.0.0 shows Presets and control source first, followed by Primary icons and then VT readings. Choose Save to keep the layout for this room.

From the live card, Controls & features → Top row icon settings opens a draft. Use Copy configuration, paste it into the same card’s dashboard code editor and save.

Set up the temperature response arc

A signed temperature rate drives the fine ring. For the optional orange VT arc, open Temperature response, select the room sensor VT uses and map a matching trend. Add either the underlying thermostat for target confirmation or a supported TRV output controller and valve-position sensor. Tap the status chip to see which observations are present.

  • Thermostat viewThe selected climate supplies dial temperature, target, supported controls and provider details.
  • Independent observationsMapped humidity, trend, valve, power, energy, room/outdoor readings and context feed the header and detail panels.

Each reading keeps its source and status. Optional response mappings combine configured room, trend and output evidence.

Additional sensor and telemetry sources are optional and depend on the integrations you use. Outdoor/weather entries are mapped readings and conditions; control policy stays with the configured provider. Independent sensor readings can reach TI without passing through VT.

Install Thermal Intelligence

Install v1.0.0 as a custom Dashboard repository. After installation, open a fresh dashboard tab and choose Thermal Intelligence Thermostat.

Home Assistant 2026.11 and later

In Marketplace, choose Add from link and add the TI repository. Select v1.0.0, finish the installation and open a fresh dashboard tab.
